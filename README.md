# تفريغ توقيتات قرآني

مستودع عام لإنتاج **ملفات توقيت دقيقة جدًا لآيات القرآن الكريم** بأصوات المشايخ، مخصصة للتكامل مع تطبيق قرآني.

## الفكرة

نأخذ تسجيلًا صوتيًا (سورة أو جزء) والنص القرآني المرجعي المعتمد، ونحدد وقت بداية ونهاية **كل آية** بالمللي ثانية، ثم نسلّم ملف JSON واحدًا لكل قارئ بصيغة جاهزة للتطبيق.

## طريقة العمل

تتبع المستودع حرفيًا [تعليمات التفريغ](تعليمات_التفريغ.md) المعتمدة في مشروع قرآني:

1. **المحاذاة الأولى** بـ stable-ts مع Whisper Small (مصدر التوقيت الأساسي).
2. **الاشتباه فقط** يُصعّد إلى Whisper Large-v3 بتفريغ حر مستقل (دون تلقين المرجع).
3. **ما بقي مشتبهًا** يُفحص بالنموذج العربي Wav2Vec2 CTC.
4. **التسليم** يرفض أي حالة معلقة، ولا يختلق زمنًا لآية غير محسومة.

قواعد صارمة مطبقة آليًا (من التعليمات):

- الرتابة الصارمة: كل آية `start_ms >= end_ms` للسابقة، ولا مدد سالبة ولا تداخل.
- `end_ms <= مدة الصوت` حتميًا — لا أبيات وهمية بعد نهاية التسجيل.
- خوارزمية منع الصدى (Zero-Reverb): بداية الآية لا ترجع خلف نهاية سابقة أكثر من 30ms، ونهايتها تمتد 100ms كحد أقصى وتتوقف قبل نطق أول حرف من الآية التالية بـ 30ms.
- السقط الحقيقي لا يُختلق له زمن؛ يُضبط كفترة انتقالية دقيقة فاصلة (200–500ms) فقط بعد ثبوته بالدليل من الصوت.
- اسم كل قارئ يُكتب بصيغة «(نسخة قرآني)» بعد اسمه.

## التشغيل: 5 آلات متزامنة

ملف الووركفلو `.github/workflows/verse-timings.yml` يقسّم التسجيلات على **5 وظائف متزامنة** (`max-parallel: 5`)، كل وظيفة تعالج تسجيلًا واحدًا (جزء أو سورة) من البداية للتسليم، ثم وظيفة نهائية تدمج النتائج وتدقّقها هيكليًا وتنشر ملف التوقيت.

التشغيل يدوي من تبويب Actions ← Verse Timings ← Run workflow:

- `reciter_index`: رقم القارئ في `sources/review_moshafs.json` (أحمد الحداد = 6).
- `tracks`: الأرقام المطلوبة (مثال: `1-30` لكل الأجزاء).
- `publish`: عند تفعيله تُCommit النتائج النهائية المجتازة إلى `timings/`.

## مخرجات مناسبة للتطبيق

كل قارئ ملف واحد في `timings/` بصيغة:

```json
{
  "reciter": "أحمد الحداد (نسخة قرآني)",
  "unit": "جزء",
  "source": "https://archive.org/download/<المعرّف>/",
  "tracks": {
    "01.mp3": {
      "url": "https://archive.org/download/<المعرّف>/01.mp3",
      "sha256": "بصمة الملف الصوتي",
      "duration_ms": 3540000,
      "verses": [
        {"num": 1, "surah": 1, "ayah": 1, "text": "بِسْمِ اللَّهِ...", "start_ms": 5000, "end_ms": 12000}
      ]
    }
  }
}
```

- `num`: ترتيب الآية داخل التسجيل (يبدأ من 1 لكل جزء/سورة).
- `text`: النص العثماني المرجعي كما هو دون تعديل.
- الأزمنة بالمللي ثانية، مطابقة لما سيسمعه المستخدم حرفيًا.
- ملف `verification.json` المرافق يثبت التدقيق الهيكلي (0 أخطاء) وعدد الآيات المطابق للمرجع.

## العلاقة بمستودع قرآني الخاص

هذا المستودع عام ولا يحتوي أي كود من التطبيق. التكامل الفعلي (إضافة التوقيتات لأصول التطبيق) يتم داخل مستودع قرآني الخاص بعد اجتياز ملف التوقيت للتحقق، وبتحليل أثر GitNexus قبل أي تعديل — وفق قواعد التكامل الصارمة في التعليمات.
